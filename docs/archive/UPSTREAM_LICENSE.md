## Key AGPL-3.0-only Implications for Morynex

### 1. Network Use Triggers Source Obligation
Unlike GPL-3.0, **AGPL-3.0 requires source code availability for network users**. If Morynex is deployed as a network service (Server edition with `motion-back`), all users interacting with it remotely must be able to download the Corresponding Source.

### 2. "AGPL-3.0-only" — No Later Versions
The project specifies `AGPL-3.0-only` (not "or any later version"). Only version 3.0 applies. Future FSF license versions do not automatically apply.

### 3. Corresponding Source Definition
Must include:
- All source code needed to generate, install, and run the object code
- Scripts to control those activities
- **Excludes:** System Libraries, general-purpose tools used unmodified

### 4. Modification Notices Required
Any modified version must carry prominent notices:
- That it was modified
- Relevant date
- That it is released under AGPL-3.0-only
- Preserve all original copyright/license notices

### 5. Interactive User Interface
If the work has an interactive UI, it must display legal notices and copyright notices appropriately.
