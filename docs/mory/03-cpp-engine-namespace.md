# Phase 3 — C++ Engine Namespace Rename

**Status:** ⏳ Planned  
**Risk:** HIGH  
**Scope:** `namespace premation` → `namespace mory` across all engine code

## Critical Constraint: Plugin ABI Compatibility
**DO NOT BREAK:** `PremationPluginInfo` and `PremationPluginExpressions` C symbols

## Strategy
1. Rename internal namespaces: `premation` → `mory`
2. **Keep exported C symbols** with aliases:
   ```cpp
   // pr_effect.h — KEEP these exact symbols
   PR_EXPORT const PrPluginInfo* PR_CALL PremationPluginInfo(void);
   PR_EXPORT const PrPluginInfo* PR_CALL MorynexPluginInfo(void);  // alias
   
   PR_EXPORT const PrExprTable* PR_CALL PremationPluginExpressions(void);
   PR_EXPORT const PrExprTable* PR_CALL MorynexPluginExpressions(void);  // alias
   ```
3. Update CMake targets and install paths
4. Update protocol codegen to emit `mory::api`
